# Collection FM

A radio station that plays from a Discogs collection, using the YouTube links attached to each release.

Live at https://silvaninja.github.io/collection-fm/

- Type a Discogs username (default `d_q`) and press **Tune in**.
- Dial in a style or decade; the announcer reads station idents between tracks.
- **Make a YouTube mix** builds a 25-track playlist link that plays on in the YouTube app with the screen locked.
